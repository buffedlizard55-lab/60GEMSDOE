Step by step

  1. Click Download the .tif above. The file is a single-band GeoTIFF, float32, EPSG:32611, 3730 × 3292, transform (100, 0, 243350, 0, −100, 4508550) — identical grid to the competition's sample_submission.tif.
  2. Every cell is finite and inside [0, 1]. Cells outside the study footprint are written as 0.0, not NaN, because the portal rejects out-of-range values with “Predicted values must be in range [0, 1]” when NaN is read as out-of-range. The -zeros suffix in the filename records that choice.
  3. Open the competition submission page → New submission → File to submit → choose the downloaded .tif (or the .zip, which contains only that TIFF).
  4. Paste this into Note (optional) (max 140 characters):
    60GEMSDOE H60-A knickpoint-corridor | chi/ksn on det_elev, >=3 independent drainages, 40000 dots off-catalogue
  5. Submit. Then record the receipt: the returned submission id and the score the page shows are the only ORGANIZER-CONFIRMED numbers this project recognises. Put them in registry/observations.jsonl.
  6. Slots are weekly and scarce. This page never spends one: promotion is a separate selector step.
