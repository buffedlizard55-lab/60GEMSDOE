D. Verification method

  • Every input is re-hashed at run time (hashlib) and compared against the pin in registry/source_pins.json; the run aborts with exit code 2 on any mismatch. No hash in this repository is quoted from memory.
  • The competition rasters were also checked band-by-band against the sibling registry's data_manifest.json (byte counts and SHA-256), which is how the mirror provenance above is stated.
  • Network note: this sandbox has no route to prd-tnm.s3.amazonaws.com; a GitHub Actions workflow in this repository (egress probe) performs the HEAD/GET checks from a runner and commits a receipt, which is the mechanism the next session should use to fetch the 10 m DEM directly.

All "s-ok" pins above were computed in this repository and are reproducible with python scripts/run_lane.py, which refuses to run if any input differs.
