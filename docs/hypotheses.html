3-5 Future Candidate Geological Hypotheses

Ranked by expected DTI improvement and implementation cost, these new hypotheses look beyond surface manifestations into distinct data correlations not captured by the current models.

1. Deep Geothermal Upflow Proxies via Magnetotelluric (MT) + Gravity Gradients

  • Layers involved: cond_surf (band 17), depth_to_base_surf (band 15), iso_grav_anom (band 13).
  • Target Physical Signature: Spatial overlap of high-gradient boundaries in both gravity (indicating basement offset) and MT conductivity (indicating fluid pathways). We look for high local gradient product `grad(grav) * grad(MT)` aligned along a single strike.
  • Why it catches hidden faults: Fluid pathways associated with geothermal activity often alter conductivity but don't always leave surface scarps. The catalogue heavily relies on surficial maps.
  • Difference from Repo: H33-D uses MT gradient orientation coherence, but this demands concordant gravity steps (basement offsets) verifying the fluid conduit is fault-hosted.
  • Implementation Cost: Low. Can be built quickly in Python with scipy.ndimage.

2. Radiometric Alteration Halos around Structural Lineaments

  • Layers involved: GeoDAWN radiometric K, Th, U (external bands), det_elev (band 12).
  • Target Physical Signature: Low K / High Th ratios indicative of hydrothermal alteration, located specifically within 300m of topographic lineaments or valleys.
  • Why it catches hidden faults: Hydrothermal alteration creates distinct radiometric signatures. Where these line up with minor topographic weaknesses not mapped as major faults, they reveal fluid-flow active structures.
  • Difference from Repo: Current models treat radiometrics as an edge detector; this explicitly models the ratio anomaly (K depletion) typical of geothermal alteration.
  • Implementation Cost: Medium. Requires accurate ratio computations robust to sensor noise.

3. Thermal Infrared Emissivity Anomalies (Requires New External Data)

  • Layers involved: ASTER or Landsat 8 TIR (Thermal Infrared), det_elev (band 12).
  • Target Physical Signature: Sub-pixel thermal anomalies aligned in linear arrays, specifically at night-time when solar heating is removed.
  • Why it catches hidden faults: Active geothermal systems emit heat along fault traces. Night-time TIR can detect subtle linear heat signatures missed by standard optical/lidar surveys.
  • Difference from Repo: Introduces direct thermal sensing, the most proximal proxy to geothermal vents, which the current repository entirely lacks.
  • Implementation Cost: High. Requires fetching ASTER/Landsat TIR from EarthExplorer/USGS APIs (free, official source: https://earthexplorer.usgs.gov), processing night-time scenes, and masking albedo effects.

4. Strain-Accumulation Zones from InSAR Velocity Gradients (Requires New External Data)

  • Layers involved: Sentinel-1 InSAR LOS velocity maps (e.g., COMET or ASF DAAC), existing USGS fault lines.
  • Target Physical Signature: Sharp linear discontinuities in InSAR unwrapped phase velocities.
  • Why it catches hidden faults: Blind faults actively accommodating strain will show subtle creep or interseismic velocity gradients across them, completely invisible to DEMs or magnetics.
  • Difference from Repo: Current repository uses static fields; InSAR introduces time-series deformation.
  • Implementation Cost: High. InSAR processing is complex; relying on pre-processed DAAC products (free, official: https://search.asf.alaska.edu/) makes it feasible but requires handling large rasters and referencing to the local grid.
