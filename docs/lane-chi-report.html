1. What was tested, and why the answer is credible

Kirby & Whipple (2012) show that bedrock-channel steepness and knickpoints record spatial gradients in rock uplift, including across active normal faults; the Perron & Royden (2013) χ transform puts channels of different size on a comparable footing (ksn = (U/K)^(1/n)), and Gailleton et al. (2019) give a reproducible segmentation rule. The physical claim under test here: a base-level step left by an active fault survives in the channel profile after the surface scarp has degraded and buried, so knickpoint crossings that align across several independent drainages on a common strike should locate faults — including faults the USGS/INGENIOUS catalogue omits.

Everything was run on the competition grid and on a buffered, whole-fault-segment hide-and-recover holdout: whole fault segments withheld with a buffer, every catalogue-derived feature built only from visible faults, visible faults masked pixel-exactly, pooled DTI with α = 0.2, β = 0.8 and a 300 m triangular kernel (56,619 withheld positive pixels). A leakage canary was run on every feature alone: maximum AUC 0.4795 — no leakage.

Two independent implementations agree. A sibling session on main (src/gems60/, differently parameterised) ran the same lane separately and also concluded NEGATIVE. Agreement across two codebases is the strongest local evidence that the STOP is a property of the method at 100 m, not of one implementation.

This archived report calls h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros an owner-reported 0.2708 raster and records 2,545 dots deleted and none added, with each removed dot 1.4–2.0 px from the mapped catalogue. The current H33-2-B2 owner claim elsewhere in this repository is 0.2778. No organizer receipt links either value to exact bytes or establishes that these records describe the same artifact; the public-board numeric matches are not file attributions (IR-60-H33-SCORE-20261011). This is a mechanism record, not score authentication. The metric can be written as

1/DTI = α + α·(F/T) + β·(|G|/T),   α = 0.2, β = 0.8.

For a new unit-mass dot with maximum kernel weight q and actual marginal weighted truth credit ΔT after maxima are recomputed, the score improves exactly when ΔT(1−αs) > αs(1−q), where s is the current DTI. Only in the special nonredundant one-truth-dot case ΔT = q = k does this reduce to k > αs. For illustrative historical values s = 0.2600–0.2778, αs = 0.052–0.0556, corresponding to roughly 283–284 m under the 300 m triangular kernel; the reported scores themselves remain unverified. This is not the general cutoff. The old comparison to 0.3195/0.3774 and the ≈45% retained-credit calculation are historical, assumption-dependent estimates, not projections or current board context; the manual 2026-10-11 public leader is 0.4133 and public rows are not project-file attributions. See the current derivation and evidence limits.

Consistency check with the live ladder: on the 57GEMSDOE site the catalogue-truth holdout ranks placements anti-monotonically against the live ladder (ρ = −0.928), which is exactly what the ceiling arithmetic predicts — better catalogue coverage is not the same as better hidden-fault coverage. This run therefore never quotes an off-catalogue curve as a score.
