Executive summary

  1. What this session did. Restored and hash-verified the pinned competition data through the public GitHub bridge (no DrivenData login exists in this sandbox), built the lane's DEM hydrology from scratch — priority-flood filling, D8 routing, exact upslope area, the Perron & Royden χ transform, ksn, a fixed-window knickpoint breakpoint detector and a cross-drainage corridor corroboration test — and ran the three budgeted experiments declared in evidence/preregistration_h60a.json.
  2. Why the highest owner-reported score (0.2778) is what it is. The metric is a budget, not a segmentation score: DTI = TPw / (TPw + 0.2 FPw + 0.8 FNw) with a 300 m triangular kernel. Adding a unit of mass raises the score only if its realised kernel weight exceeds 0.2 × DTI. The 0.2778 file is a thin emission (37,654 dots) with every dot at least 200 m off the mapped catalogue: it removed mass the metric taxes at 0.2 per pixel while keeping the credit. Its audit JSON is in GEMSDOE32.
  3. Can we beat it? Only with a better field, not a better budget: at the same 40 k dots the mean realised credit must rise ~25% to reach the board leaders. This lane attacked exactly that with an independent physical observable (channel steepness steps) that no scarp-, magnetic- or damage-zone-lane submission uses — and on the only instrument available in this sandbox it did not beat it. It did not beat random mass either. That is the answer this session can defend, and it is why the file is released for research rather than for a slot.
  4. Result: NEGATIVE, and reported as such. The mandated first test passed (+0.1089 log-ksn, 95% CI [+0.0586, +0.1569], 323 withheld components), but the emission built from it scores HOLDOUT-DTI 0.01639 [0.01223, 0.02061] against 0.03908 for random mass at the same budget and 0.19073 for the distance-to-visible control. It loses to every control, so the pre-registered promotion gate fails and the file is released for research only.
  5. What is measured here. Everything below is HOLDOUT-DTI (shared evaluator gems57-pooled-hide-v2) or MEASUREMENT. Nothing on this page is an organizer score; no receipt exists.
